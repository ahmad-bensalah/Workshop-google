# Contributing

Found a typo, a confusing explanation, or a command that didn't work? Contributions
are welcome, and making one is great practice for [lesson 11](docs/11-team-workflows.md)!

1. Fork this repository and clone your fork.
2. Create a branch: `git switch -c fix/<short-description>`.
3. Make your change. Keep the tone friendly and beginner-focused; explain every
   new command you introduce.
4. Commit with a clear message, e.g. `docs: clarify reset --soft example`.
5. Push to your fork and open a pull request describing what you changed and why.
