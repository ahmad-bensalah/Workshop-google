# Labs

Hands-on exercises. Do each lab right after its lesson. Work in a scratch folder
such as `~/git-practice`, **not** inside this workshop repository.

| Lab | After lesson | Topic |
|-----|--------------|-------|
| [Lab 1](lab-01-setup.md) | 1 | Install and configure |
| [Lab 2](lab-02-first-commits.md) | 2 | First repository and commits |
| [Lab 3](lab-03-history.md) | 3 | Exploring history and diffs |
| [Lab 4](lab-04-undo.md) | 4 | Undoing mistakes |
| [Lab 5](lab-05-branches.md) | 5 | Branches |
| [Lab 6](lab-06-conflicts.md) | 6 | Merge conflicts |
| [Lab 7](lab-07-github.md) | 7 | GitHub, push and pull |
| [Lab 8](lab-08-rebase.md) | 8 | Rebase and cleaning history |
| [Lab 9](lab-09-stash-tags.md) | 9, 10 | Stash and tags |
| [Lab 10](lab-10-pull-request.md) | 11 | Your first pull request |
| [Lab 11](lab-11-rescue.md) | 13 | Rescue missions: reflog, cherry-pick, bisect |
| [Final challenge](final-challenge.md) | all | Put it all together |

Each lab has **tasks**, **checkpoints** (how to verify you got it right), and
answers in [solutions.md](solutions.md). Try on your own first!

Some labs use helper scripts from [`../scripts/`](../scripts/) that build a practice
repository for you. Run them with `bash`, for example:

```bash
cd ~/git-practice
bash /path/to/git-workshop/scripts/make-conflict-repo.sh
```

On Windows, run the scripts from **Git Bash**.
